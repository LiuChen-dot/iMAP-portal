# 2.4.4 方案 B：可访问性与安全加固 — 详细说明

本文档把「可访问性与安全加固」拆成**四条具体修改**，每条说明：改什么、为什么、在哪个文件改、怎么改。

---

## 一、给 iframe 加 `title`（无障碍）

### 改什么
嵌入基因组浏览器的 iframe 目前没有 `title`。读屏软件（视障用户）无法知道这个框里是什么内容。

### 在哪改
**文件**：`zwportal/src/views/cytoscape/index.vue`  
**位置**：模板里的 `<iframe>` 标签。

### 当前写法
```html
<iframe id="iframeViewer" class="genbro-iframe" :src="iframeUrl" style="..."></iframe>
```

### 改成什么样
给 iframe 增加 `title`，用一句话描述内容（可配合 i18n 后续做中英文）：
```html
<iframe
  id="iframeViewer"
  class="genbro-iframe"
  :src="iframeUrl"
  title="基因组浏览器"
  style="...">
</iframe>
```

### 效果
读屏会读成「基因组浏览器，框架」之类，用户能知道这是基因组浏览器区域。

## 二、基因详情页「Genome Browser」改成可聚焦、可键盘操作（无障碍）

### 改什么
现在「Genome Browser」是一个普通的 `<div @click="openCytoscape">`。用键盘 Tab 无法聚焦到这里，也不能用回车/空格触发，对键盘用户和无障碍不友好。

### 在哪改
**文件**：`zwportal/src/views/Search/Gene.vue`  
**位置**：标题右侧那一块「Genome Browser」的 div。

### 当前写法
```html
<div @click="openCytoscape" v-if="zwType == 'gene'"
  style="background-color: #A8D159;color: white;padding:5px 12px;border-radius: 8px;cursor: pointer;...">
  Genome Browser
</div>
```

### 改成什么样（两种任选其一）

**方式 1：直接用按钮（推荐）**
```html
<button
  type="button"
  v-if="zwType == 'gene'"
  @click="openCytoscape"
  style="background-color: #A8D159;color: white;padding:5px 12px;border-radius: 8px;cursor: pointer;border: none;..."
>
  Genome Browser
</button>
```
- 按钮天然可 Tab 聚焦、回车/空格触发，无需额外属性。

**方式 2：保留 div，但加上「按钮」语义和键盘支持**
```html
<div
  v-if="zwType == 'gene'"
  role="button"
  tabindex="0"
  @click="openCytoscape"
  @keydown.enter="openCytoscape"
  @keydown.space.prevent="openCytoscape"
  style="...">
  Genome Browser
</div>
```
- `role="button"`：告诉读屏「这是一个按钮」。
- `tabindex="0"`：可被 Tab 聚焦。
- `@keydown.enter` / `@keydown.space.prevent`：键盘回车或空格时执行同一逻辑。

### 效果
键盘用户可以用 Tab 切到「Genome Browser」并用回车打开；读屏能正确报出这是按钮。

## 三、postMessage 用具体 targetOrigin，父页校验 event.origin（安全）

### 改什么
- **iframe 里**：现在发消息是 `parent.postMessage("Genbro Ready", "*")`，第二个参数 `"*"` 表示「任何网页都可以收到」。若你们的页面被嵌到别人/恶意站里，别人也能收到这条消息，理论上可被利用。
- **父页**：现在只判断 `event.data === 'Genbro Ready'`，没有判断消息是否真的来自你们的 iframe（`event.origin`）。若别的页面或扩展也发了同一条文字，父页也会执行，存在误触发或恶意触发风险。

### 在哪改
- **发消息的一方**：`zwportal/public/genbro/genbro.js`（iframe 里的脚本）。
- **收消息的一方**：`zwportal/src/views/cytoscape/index.vue`（父页）。

### 当前写法

**genbro.js 里（约第 34 行）：**
```javascript
parent.postMessage("Genbro Ready", "*");
```

**cytoscape/index.vue 里：**
```javascript
function onMessage(event) {
    if (event.data !== 'Genbro Ready') return;
    runGenBro();
}
```

### 改成什么样

**genbro.js**  
- 不再用 `"*"`，改成「父页所在源」（和父页同源时，用 `document.referrer` 或由父页先发一条带 origin 的消息再回传，实现稍复杂）。  
- **简单做法**：iframe 和父页同源（同一域名+端口），则 iframe 里可以用 `parent.location.origin` 或直接写死你们生产/开发的前端域名。例如：
```javascript
// 与父页同源时，只发给父页，不发给任意网页
var targetOrigin = (parent !== window.self && parent.location && parent.location.origin)
  ? parent.location.origin
  : window.location.origin;
parent.postMessage("Genbro Ready", targetOrigin);
```
这样只有和 iframe 同源的父页能收到（同源下 `parent.location.origin` 可访问）。

**cytoscape/index.vue**  
- 只接受「来自自己页面」或「来自可信源」的消息，例如只接受当前页面的 origin：
```javascript
function onMessage(event) {
    if (event.data !== 'Genbro Ready') return;
    // 仅接受来自同源或本机开发环境的消息
    const allowedOrigins = [
        window.location.origin,
        'http://localhost:89',
        'http://127.0.0.1:89'
    ];
    if (!allowedOrigins.includes(event.origin)) return;
    runGenBro();
}
```
上线时把 `allowedOrigins` 改成你们实际的前端访问地址列表（或从配置读），避免写死。

### 效果
- 只有和你们约定好的页面能收到「Genbro Ready」。
- 父页只响应来自可信 origin 的消息，避免被别的网站或扩展误触发。

## 四、Font Awesome 改为本地或自有静态资源（依赖与安全）

### 改什么
genbro.html 里图标和部分样式来自 CDN：
```html
<link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/5.13.1/css/all.min.css" ...>
```
若 CDN 挂了、被墙或被篡改，会影响基因组浏览器界面；且会向第三方发起请求，有隐私/合规考量。

### 在哪改
**文件**：`zwportal/public/genbro/genbro.html`  
**位置**：`<head>` 里那条 Font Awesome 的 `<link>`。

### 当前写法
```html
<link rel="stylesheet" type="text/css"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/5.13.1/css/all.min.css">
```

### 改成什么样（两种思路）

**方式 1：下载到项目里（推荐）**  
1. 下载 [Font Awesome 5.13.1](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/5.13.1/css/all.min.css) 的 all.min.css，以及其引用的 webfonts 文件（.woff2 等）。  
2. 放到例如 `zwportal/public/genbro/fontawesome/` 下，保持相对路径（如 `../webfonts/xxx.woff2`）。  
3. 把 link 改成指向本地：
```html
<link rel="stylesheet" type="text/css" href="fontawesome/all.min.css">
```

**方式 2：继续用 CDN，但加备用**  
若暂时不想动文件结构，可保留 CDN，在项目里放一份同版本 CSS 作为 fallback（用 JS 检测加载失败再插入本地 link），复杂度较高，一般直接本地化即可。

### 效果
不依赖外网 CDN 也能正常显示图标；减少对外部域名的请求，便于内网/合规环境部署。

---

## 五、小结（改什么、改哪、目的）

| 序号 | 改什么 | 文件 | 目的 |
|------|--------|------|------|
| 1 | iframe 加 `title="基因组浏览器"` | cytoscape/index.vue | 读屏能说出这是基因组浏览器 |
| 2 | 「Genome Browser」改为 `<button>` 或 div+role+tabindex+键盘事件 | Search/Gene.vue | 键盘可聚焦、可触发，无障碍 |
| 3 | postMessage 用 targetOrigin；父页校验 event.origin | genbro.js + cytoscape/index.vue | 只对同源/可信页通信，降低被滥用风险 |
| 4 | Font Awesome 用本地 CSS（+webfonts） | genbro/genbro.html | 不依赖 CDN，内网/合规更稳 |

按上面四条逐项改，就是「2.4.4 方案 B：可访问性与安全加固」的完整落地；若某一条你们环境不需要（例如不做无障碍审计），可以只做 3 和 4 做安全与依赖加固。
