# 16S 测序分析模块 — 项目概览优化说明

**文档类型**：项目进展说明  
**涉及模块**：16S 测序分析 — 项目概览  
**修改文件**：`zwportal/src/views/16S/index.vue`

---

## 一、修改概述

对 16S 测序分析模块中「项目概览」页面的布局与排版进行了优化，并解决了在不同缩放比、不同窗口宽度下出现的单侧大面积空白问题，最终采用「内容区最大宽度 1200px + 居中对齐」的方案，兼顾阅读体验与视觉平衡。

---

## 二、调整背景与问题

### 2.1 初始问题

- **布局与层级**：项目概览原为平铺长文案，仅依赖简单 padding/margin 工具类，缺少区块划分与标题层级，可读性一般。
- **响应式与留白**：在不同缩放比、不同分辨率下表现不一致，有时**左侧**出现大面积空白，有时**右侧**出现大面积空白，内容未合理利用主内容区宽度，视觉不均衡。

### 2.2 优化目标

- 提升项目概览的结构化与可读性（分块、标题、列表、留白）。
- 保证主内容区在不同缩放与宽度下布局稳定，避免单侧大面积空白。
- 在控制行宽、保证阅读舒适的前提下，尽量利用可用宽度并保持版式美观。

---

## 三、调整过程（按时间顺序）

### 3.1 第一轮：项目概览布局与排版优化

**内容：**

- 将项目概览由平铺 div 改为语义化结构：使用 `<section>` 分块，`<h2>`/`<h3>` 区分标题层级，`<p>` 段落、`<ul>` 列表。
- 一级标题统一为左侧主题色竖条 + 加粗样式（如：整体介绍、产品介绍、一站式解决方案、作图插件升级、产品优势、分析流程）。
- 「随心定制」与「主流序列降噪」改为两列网格卡片，浅灰背景、圆角，小屏下自动单列。
- 产品优势列表采用主题色圆点样式，替代默认列表符号。
- 分析流程图为独立区块，带圆角与浅底容器。
- 正文统一行高、段间距与两端对齐，内容区设置 `max-width: 900px` 并**居中**（`margin: 0 auto`），以控制阅读宽度。

**结果：** 阅读层级和版式明显改善，但为控制行宽采用的「900px 居中」在部分场景下会带来单侧留白。

---

### 3.2 第二轮：解决「左侧一大块空白」

**现象：** 某些缩放比或窗口下，主内容区**左侧**出现大面积空白。

**修改：**

- 整体容器：`.box` 增加 `box-sizing: border-box`、`width: 100%`，保证占满父级宽度。
- 左侧导航：`.navigatebox` 增加 `flex-shrink: 0`，固定宽度不随缩放被压缩。
- 右侧内容区：`.content` 由 `flex: 5` 改为 `flex: 1`，并增加 `min-width: 0`，避免 flex 子项默认 `min-width: auto` 导致宽度计算异常。
- 项目概览：`.overview-inner` 取消居中，改为 `margin: 0`，内容**左对齐**，并保留 `max-width: min(900px, 100%)`。

**结果：** 左侧空白问题消除，但在较宽窗口下**右侧**出现较大留白。

---

### 3.3 第三轮：方案选择与「右侧空白」处理

**现象：** 左对齐 + 900px 上限后，右侧主内容区留白明显。

**提供的可选方案：**

1. **方案一**：内容区拉满，取消 max-width（可能行过长）。
2. **方案二**：保持左对齐 + 最大宽度，将上限从 900px 提高到 1200px 或 1400px（推荐，改动小）。
3. **方案三**：宽屏下采用两栏排版，铺满宽度。
4. **方案四**：响应式上限 + 宽屏时居中，使左右留白对称。

**选定方案：** **方案二** — 提高阅读宽度上限至 **1200px**，保持左对齐。

**实施：** 将 `.overview-inner` 的 `max-width: min(900px, 100%)` 改为 `max-width: min(1200px, 100%)`。

**结果：** 右侧空白明显减小，内容区利用更充分。

---

### 3.4 第四轮：改为居中对齐

**需求：** 在方案二基础上，将项目概览内容改为**居中对齐**，使宽屏下左右留白对称、版式更规整。

**实施：** 将 `.overview-inner` 的 `margin: 0` 改为 `margin: 0 auto`。

**结果：** 项目概览在右侧主内容区内居中显示，最大宽度 1200px，宽屏下左右留白对称，阅读宽度与视觉平衡兼顾。

---

## 四、最终修改要点汇总

| 类别           | 说明 |
|----------------|------|
| **结构**       | 项目概览使用 `<section>`、`<h2>`/`<h3>`、`<p>`、`<ul>` 等语义化标签，分块清晰。 |
| **标题**       | 一级标题左侧 4px 主题色竖条 + 加粗；二级标题用于两列卡片内。 |
| **两列卡片**   | 「随心定制」「主流序列降噪」为两列网格，浅灰背景、圆角，小屏单列。 |
| **列表**       | 产品优势为圆点列表，主题色圆点、合适行高与间距。 |
| **整体布局**   | `.box` 全宽、左侧导航固定不缩放；`.content` 使用 `flex: 1`、`min-width: 0`，避免异常留白。 |
| **概览宽度与对齐** | `.overview-inner`：`max-width: min(1200px, 100%)`，`margin: 0 auto`，居中对齐。 |
| **响应式**     | 小屏下两列卡片改为单列；内容区宽度使用 `min(1200px, 100%)` 自适应。 |

---

## 五、当前状态与结论

- **项目概览**：结构清晰、层级明确、留白统一，阅读体验与版式均优于调整前。
- **留白与对齐**：通过容器全宽、flex 稳定、1200px 上限与居中对齐，在不同缩放比和窗口宽度下不再出现单侧大面积空白，宽屏下左右留白对称。
- **可维护性**：样式集中在 `index.vue` 的 scoped 样式中，类名语义化（如 `overview-section`、`overview-title`、`overview-card`），便于后续扩展或再调整。
